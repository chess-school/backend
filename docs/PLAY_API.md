# Онлайн-партии — `/api/v2/play` и socket.io `/play`

Здесь описана игра человек против человека: рейтинг Glicko-2, серверные часы, вызовы по ссылке, открытое лобби и автоподбор.
Ошибки — `{ msg, code, details? }`. В сокете ошибки приходят в ack: `{ ok: false, error: { msg, code } }`.

## Рейтинг

- Модель: `User.ratings.{bullet|blitz|rapid|classical} = { rating: 1500, rd: 350, vol: 0.06, games: 0 }`.
- Формула: Glicko-2 (`v2/utils/ratingCalculator.js`), рейтинг пересчитывается после каждой рейтинговой партии, τ = 0.75.
- Пока RD > 110, рейтинг считается предварительным (`provisional`, «?» как на Lichess).
- Категория партии зависит от ожидаемой длительности: время + 40 × добавка.

| Длительность, с | Категория |
|---|---|
| меньше 180 | bullet |
| меньше 480 | blitz |
| меньше 1500 | rapid |
| остальное | classical |

## Контроль времени

- Пресеты: `1+0, 2+1` (bullet), `3+0, 3+2, 5+0, 5+3` (blitz), `10+0, 15+10` (rapid), `30+0` (classical).
- Свой контроль: 1–180 минут и добавка 0–60 секунд.
- Список пресетов и пределы: `GET /play/presets`.

## Модель `LiveGame`

Имя `Game` уже занято базой партий мастеров, поэтому модель называется `LiveGame`.

- Статусы: `created` → `active` → `finished`, а также `aborted`.
- Итог партии:
  - `winner`: `white`, `black`, `draw`;
  - `endReason`: `checkmate`, `timeout`, `resignation`, `draw_agreement`, `stalemate`, `insufficient_material`, `threefold_repetition`, `fifty_moves`, `aborted`.
- Ходы: `moves` (UCI) и `sanMoves`.
- Часы: `clock { whiteMs, blackMs, turnStartedAt }`.
- Рейтинг: `ratingChanges { white, black }` и `ratings.{white|black} = { before, after, diff, provisional }`.

## REST

| Метод и путь | Кто | Что делает |
|---|---|---|
| `GET /play/presets` | все | Пресеты и пределы контроля времени |
| `GET /play/me` | вошедший | Мои рейтинги по категориям, активные партии, мои вызовы |
| `GET /play/games?limit=` | вошедший | Мои завершённые партии |
| `GET /play/games/:id` | все | Полное состояние партии, в том числе вызова в статусе `created` |
| `GET /play/challenges` | вошедший | Открытые вызовы лобби: живут 1 час, свои помечены `mine: true` |
| `POST /play/challenges` | вошедший | Создать вызов `{ minutes, increment, rated, color: white\|black\|random, isPrivate, ratingRange? }` |
| `POST /play/challenges/:id/accept` | вошедший | Принять вызов, ответ `{ gameId }`. Принятие атомарное |
| `DELETE /play/challenges/:id` | создатель | Отозвать вызов |

**Закрытый вызов** (`isPrivate: true`) открывается по ссылке `/play/<id>` и действует 24 часа.

**Коды ошибок вызовов:**

| Код | Статус | Когда |
|---|---|---|
| `INVALID_TIME_CONTROL` | 422 | Контроль времени вне пределов |
| `TOO_MANY_CHALLENGES` | 409 | Больше 3 открытых вызовов |
| `OWN_CHALLENGE` | 409 | Попытка принять свой вызов |
| `CHALLENGE_TAKEN` | 409 | Вызов уже принят или отозван |
| `CHALLENGE_EXPIRED` | 410 | Срок вызова истёк |
| `RATING_OUT_OF_RANGE` | 403 | Рейтинг не входит в диапазон рейтингового открытого вызова |

## Сокет `/play`

Подключение: `io('<host>/play', { auth: { token } })`. JWT проверяется так же, как в REST.

**Клиент → сервер** (все события с ack):

| Событие | Данные | Что делает |
|---|---|---|
| `join_game` | `{ gameId }` | Подписка на партию; в ack — полное состояние, как в `GET /play/games/:id`. Можно смотреть и чужую партию |
| `leave_game` | `{ gameId }` | Отписка от партии |
| `make_move` | `{ gameId, uci, ply? }` | Ход. `ply` — сколько ходов на доске клиента; если позиция у клиента устарела, ход отклоняется |
| `offer_draw` | `{ gameId }` | Предложить ничью. Встречное предложение — это согласие. Ход соперника отклоняет предложение |
| `accept_draw` / `decline_draw` | `{ gameId }` | Принять или отклонить ничью |
| `resign` | `{ gameId }` | Сдаться. До первых ходов обеих сторон сдача считается отменой |
| `abort` | `{ gameId }` | Отменить партию; только до первых ходов обеих сторон |
| `seek` | `{ minutes, increment, rated, ratingRange? }` | Встать в очередь автоподбора |
| `cancel_seek` | — | Выйти из очереди |
| `rematch` | `{ gameId }` | Предложить реванш. Если соперник уже предложил — реванш принимается |

**Сервер → клиент:**

| Событие | Комната | Данные |
|---|---|---|
| `move` | `game:<id>` | `{ gameId, uci, san, fen, ply, clock, drawOfferBy }` |
| `game_over` | `game:<id>` | `{ gameId, status, winner, endReason, ratingChanges, ratings, clock, pgn }` |
| `draw_offer` / `draw_declined` | `game:<id>` | `{ gameId, by }` |
| `rematch_offer` | `game:<id>` и `user:<id>` | `{ gameId, newGameId, by }` |
| `game_started` | `user:<id>` | `{ gameId }` — вызов принят или найден соперник |
| `seek_state` | `user:<id>` | `{ seeking, gameId? }` |

`clock = { whiteMs, blackMs, turn, running, serverNow }`. Клиент сам отсчитывает время от `serverNow`, но решение о падении флага принимает только сервер.

**Коды ошибок ходов и действий:**

| Код | Когда |
|---|---|
| `ILLEGAL_MOVE` | Ход нелегален (проверяется chess.js на сервере) |
| `INVALID_MOVE_FORMAT` | Ход не в формате UCI |
| `NOT_YOUR_TURN` | Сейчас ход соперника |
| `NOT_A_PLAYER` | Ход или действие от зрителя |
| `STALE_POSITION` | Позиция у клиента устарела |
| `TIME_UP` | Флаг упал раньше, чем пришёл ход |
| `GAME_NOT_ACTIVE` | Партия не идёт |
| `GAME_NOT_FOUND` | Партия не найдена |
| `ABORT_NOT_ALLOWED` | Отмена после первых ходов обеих сторон |
| `DRAW_NOT_ALLOWED` | Ничья до первых ходов |
| `NO_DRAW_OFFER` | Принять или отклонить нечего |
| `INVALID_ID` | Некорректный `gameId` |

## Часы (`v2/services/play/clock.js`)

- Часы не идут, пока обе стороны не сделали первый ход. Если первый ход не сделан за 30 секунд, партия отменяется.
- После хода у сходившего списывается потраченное время и прибавляется добавка.
- Флаг падает по серверному таймеру. Ход, пришедший позже флага, не засчитывается.
- Если флаг упал, а у соперника нет материала для мата (только король или король с одной лёгкой фигурой), объявляется ничья.

## Ограничения

- Активные партии и очередь автоподбора хранятся в памяти одного процесса.
- После перезапуска сервера активная партия восстанавливается из БД при первом обращении: ходы, остатки часов и время начала текущего хода. Флаг, упавший за время простоя, засчитывается.
- Если бэкенд запустить в нескольких экземплярах, нужен общий брокер, например `@socket.io/redis-adapter`, и закрепление партий за экземплярами. Сейчас этого нет.
